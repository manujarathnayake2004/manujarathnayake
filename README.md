# Manuja Rathnayake portfolio

Personal portfolio hosted with GitHub Pages.

https://manujarathnayake2004.github.io/manujarathnayake/

## Pages

- `index.html` contains the profile, work experience, education, skills, projects and contact details.
- `Graphic_Designing.html`, `Programming.html`, `Mobile_UI_UX.html` and `Web_development.html` contain the work galleries.
- `portfolio.css` provides the shared responsive dark blue styling.
- `portfolio.js` enhances mobile navigation and image previews. Content and links work without JavaScript.
- CV downloads use `Manuja_Rathnayake_CV.pdf` across the homepage and galleries.

This is a static website with no build step. GitHub Pages deploys from the root of the main branch.

## Content updates

Edit the HTML files to update content. Replace `Manuja_Rathnayake_CV.pdf` when publishing an updated CV. Older CV files have been removed from the current published site. Gallery images link directly to the existing artwork, with a native dialog enhancement where supported.

The contact section opens an email app or WhatsApp. The website does not collect form submissions.

Profile and career information were refreshed from the supplied CV in October 2026. Featured software descriptions are based on the linked project repositories.
